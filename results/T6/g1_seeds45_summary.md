# G1 种子 4、5 汇总（PLAN §3g-16 第 3 条、§3g-17 (b)）

口径同 `src/t6/pareto.py` 的 accuracy()：每个种子取最后一个 epoch 的测试精度（`experiments/T6/models/g1/<cfg>_t<seed>.json` 的 `test_acc`），均值与标准差（ddof = 1）。脚本 `src/t6/g1_seeds45.py`，表 `experiments/T6/g1_seeds45.csv`（42 个配置，即队列 g1s45_* 全部：MLP 7、MLP+正则 8、dANN-G 21、dANN-G-2:4 3、CNN 3；dann24 不在其中）。种子 1–3 的均值与 `experiments/T6/fmax/pareto_g1.csv` 逐行一致（42/42，差 ≤ 1e-4）。种子 4、5 无缺失（84/84）。

**结论：五种子与三种子的结论一致。** 五种子均值相对三种子的偏移最大为 −0.19 个百分点（dannG_p4_m16_s64_sg1：89.86 → 89.67；其次 mlpreg_h256_do0.2_wd0.0005 −0.19、mlpreg_h1024_do0.2_wd0.0005 −0.16、mlp_h2048 −0.15），绝对偏移平均 0.06 个百分点，整体略偏低（32 个配置下降、10 个上升，平均 −0.04）。只有 1 个配置的偏移超过其三种子标准差（最大为 1.9 倍，即 m16_s64_sg1，其三种子标准差只有 0.10）。三种子与五种子均值的秩相关 Spearman ρ = 0.99。各族最好值：dANN-G 90.41 → 90.42（最好配置由 m32_s256_sg4 换成 m64_s128_sg4，二者相差 0.03 个百分点，在噪声内），MLP 89.29 → 89.28（h1024，仍不超过 89.3%），MLP+正则 89.46 → 89.32，dANN-G-2:4 90.24 → 90.29，CNN c32_64 90.68 → 90.65（仍为全表最高）。因此 dANN-G 对最好 MLP 的优势约 +1.1 个百分点（五种子 +1.14，三种子 +1.12），对最好 MLP+正则为 +1.10（三种子 +0.95），方向和量级都不变。这些都是 `--no_export` 的训练，只有精度，不涉及延迟。
